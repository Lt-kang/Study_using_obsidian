# 성능지표

## mATE(mean Average Translation Error)
- pred bbox center point와 GT bbox center point의 평균 거리 오차(meter)
- **낮을수록 좋음**
> 박스를 어디에 찍었는지에 대한 정확도


## mASE (mean Average Sclae Error)
- 박스 크기(scale)의 오차
- **낮을수록 좋음**
>차를 크게 봤는지, 작게 봤는지


## mAOE (mean Average Orientation Error)
- 박스의 yaw 방향 각도 오차
- degree (or radian)
- **낮을수록 좋음**
> 차가 어느 방향을 보고 있는지


## mAVE (mean Average Velocity Error)
- 객체 속도 예측 오차 (m/s)
- **낮을수록 좋음**
>움직이는 방향과 속도를 잘 맞추는가?


## mAAE
- 객체 속성(attribute) 분류 오류
- **낮을수록 좋음**
> 객체 상태 분류 정확도


## mAP(mean Average Precision)
- 3D Object Detection의 기본 정확도 지표
- GT bbox와 prediction bbox의 center distance threshold 기준으로 계산
- **높을수록 좋음**
> 객체를 얼마나 잘 찾았는가?


## NDS
- 위 지표들의 종합 점수
```
NDS = 0.5 × mAP
    + 0.1 × (1 − mATE)
    + 0.1 × (1 − mASE)
    + 0.1 × (1 − mAOE)
    + 0.1 × (1 − mAVE)
    + 0.1 × (1 − mAAE)
```
> nuScenes에서 사용하는 종합 점수


# 요약

- mATE: : center point 거리 오차
- mASE: bbox 크기
- mAOE: yaw 방향
- mAVE: 객체 속도
- mAAE: 객체 속성
- mAP: 3D bbox 평균 Precision
- NDS: 위 모든 지표의 종합
