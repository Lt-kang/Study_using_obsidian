# Abstarct
- Transfusion은 convolutional backbones와 transformer decoder 기반의 detection head로 구성된다.
  `Specifically, our TransFusion consists of convolutional backbones and a detection head based on a transformer decoder`
- decoder의 첫번째 layer는 sparse set of object queries를 사용하여 point cloud로부터 초기 bounding box를 예측한다.
- decoder의 두번째 layer는 공간적(spatial) 문맥적(contextual) 관계를 활용하여 object query와 유용한 image fueature를 adaptively fuse 한다.
- transformer의 attention 메커니즘은 image의 "어디서" 그리고 "무슨" 정보를 가져와야 하는지를 모델이 스스로 결정하게 해주며, 그 결과 강건하고 효과적인 fusion 전략을 만든다.
  또한 point cloud에서 탐지하기 어려운 object를 다루기 위해 image-guided query initialization 전락도 설계하였다.


# Transfusion vs Transfusion-LiDAR
## Transfusion
### 원리
- LiDAR로 초기 3d bbox 생성
- 이미지에서 feature를 가져온 이후 cross-attention으로 필요한 정보만 soft하게 가져와서 보강함. (bbox를 보강하는 거)
		- 조명 불량 / calibration 오차를 보강함.

# 배운 점
1. transfusion이 LiDAR only만으로도 3d detection이 될 수 있는 이유는
   point cloud로 init 3d box를 먼저 detection하기 때문이다.
2. point cloud로 init 3d box를 먼저 detection한 이후 image feature를 soft association을 통해 calibration 및 이미지 어두움/역광/노이즈 등의 이슈를 해결한다.
