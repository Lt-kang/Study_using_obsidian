# 요약
- config > 프로젝트/실험의 "설정값"
	- 무엇으로 학습할 것인가?
- arguments > 실행 시점의 "의도/트리거"
	- 이번에는 무엇을 할 것인가?

|구분|config|arguments|
|---|---|---|
|변경 시점|실행 전 미리 정의|실행할 때마다|
|변경 빈도|낮음|높음|
|저장 여부|반드시 저장 (재현성)|로그만 남겨도 됨|
|역할|실험/시스템의 **상태 정의**|실행 흐름의 **의사결정**|
|표현 방식|yaml / json / dataclass|CLI flag / argparse|
|책임|“실험을 규정”|“실험을 시작”
